## 固定規則（Stone 規定，每隻角色都照做）

1. **拳套和手上的道具不可以藏到頭後面，疊圖一律在頭前面**（2026-10-28）。所以生圖時拳套（含後手）要整顆畫完、和臉的輪廓分開，不要被臉或頭髮蓋掉一角；`layers.json` 裡 `fist_*`、`glove_*`、`prop_*`、`weapon_*` 都排在 `head.png` 後面。排錯的話 `spine-motion character` 報告會標 ⚠。
2. **大圖騰一律要有框，和小圖同款**（2026-10-28）。這隻角色所在的遊戲如果也要出符號圖：高分符號（大圖騰）和低分符號（小圖）用同一款框、同樣大小，即使參考的原版遊戲大圖騰沒框也一樣。
3. 先畫一張完整的全身圖，確認成人形後再拆；不要用零件圖集拼。
4. 被擋住的地方畫完；關節兩邊重疊，**重疊處不要描邊**，多畫的部分不超出相鄰部件的外緣；關節不要切平。

## 2. 姿勢

- **面向右**的拳擊架式，側面稍微轉向觀眾（3/4）。前手拳套在下巴高度往前伸；後手拳套護在臉頰旁；兩肘彎約 90°。
