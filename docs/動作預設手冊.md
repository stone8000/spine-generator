## fighter-idle-bounce

**格鬥待機・彈跳型（Iron Jaw 左角色實測）**（循環）

原地上下彈跳、雙拳交替。數值取自 Iron Jaw 左角色的畫面量測（週期 1.99 秒、正弦吻合度 R² 0.998）。

| 角色 | 必填 | 說明 |
|---|---|---|
| `hip` | 是 | 上身根骨（髖） |
| `head` |  | 頭 |
| `shoulderBack` |  | 後側肩膀 |
| `fistFront` |  | 前手拳（建議用 IK 目標骨） |
| `fistBack` |  | 後手拳（建議用 IK 目標骨） |
| `hair`（骨骼清單） |  | 頭髮骨骼鏈，由根到尾 |

| 參數 | 預設值 | 說明 |
|---|---|---|
| `period` | `2` | 循環秒數（實測 1.99） |
| `intensity` | `1` | 動作幅度倍率 |
| `hair` | `"keys"` | 頭髮鏈：'keys'（模擬 Spine 物理後烘成可編輯的關鍵影格）、'physics'（保留 runtime 物理約束）、'none' |

```json
{
  "name": "fighter_idle_bounce",
  "preset": "fighter-idle-bounce",
  "params": {
    "period": 2,
    "intensity": 1,
    "hair": "keys"
  }
}
```

## chain-sway

**甩尾跟隨（頭髮、尾巴、披風、緞帶）**（循環）

沿骨骼鏈傳遞的波：每一節比上一節晚幾幀、幅度略大，形成自然的甩動。也可改用 Physics。

| 角色 | 必填 | 說明 |
|---|---|---|
| `chain`（骨骼清單） | 是 | 骨骼鏈，由根到尾 |

| 參數 | 預設值 | 說明 |
|---|---|---|
| `amplitude` | `6` | 第一節擺動角度（度） |
| `period` | `2` | 循環秒數 |
| `lagFrames` | `3` | 每一節延遲幾幀（@30） |
| `gain` | `1.2` | 每一節幅度倍率 |
| `mode` | `"keys"` | 'keys'（數學波）、'bake'（模擬物理後烘成關鍵影格）、'physics'（保留 runtime 物理） |

```json
{
  "name": "chain_sway",
  "preset": "chain-sway",
  "params": {
    "amplitude": 6,
    "period": 2,
    "lagFrames": 3,
    "gain": 1.2,
    "mode": "keys"
  }
}
```
