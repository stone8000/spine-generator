# stand34：正面 3/4 站姿模板

給「用手說話」的表演型角色：催眠師、魔術師、馬戲團長、主持人。拳擊架式模板做不了的拉眼鏡、點帽、
聳肩、摘帽，在這裡是基本動作。第一個用它的角色是 Hypno Monkey 的催眠師猴。

```bash
spine-motion character <圖層資料夾>      # 檔名照下表，工具自動認出是 stand34
```

## 姿勢

- 畫布 1024×1536，地面點 (512, 1456)。身體朝**畫面左**轉約 30°（盤面在角色左邊）。
- **L / R 照畫面分**：L＝畫面左的手腳（遠側，畫在軀幹後面），R＝畫面右（近側，畫在軀幹前面）。
- 雙腳分開、不交叉，**膝蓋微彎**：腿畫直了，身體一往上彈腿就鎖死、IK 會頓（工具會自動限制彈跳高度，但動作會變小）。
- R 手（近手）手肘彎約 100°、停在胸口；L 手（遠手）插腰。

## 圖層

由後到前；同一格的多個檔名是「換圖」，畫在同一個位置，動作會切換。

| 圖層（slot） | 檔名 | 必要 |
|---|---|---|
| 尾巴三段 | `tail_3`、`tail_2`、`tail_1` | |
| 燕尾 | `coat_tail_l`、`coat_tail_r` | |
| L 手 | `arm_l_upper`、`arm_l_lower`、`hand_l_hip` / `hand_l_point` / `hand_l_open` | ✓ |
| L 腿 | `leg_l_upper`、`leg_l_lower`、`foot_l` | ✓ |
| 骨盆 | `pelvis` | ✓ |
| R 腿 | `leg_r_upper`、`leg_r_lower`、`foot_r` | ✓ |
| 脖子 | `neck` | |
| 上身 | `torso` | ✓ |
| 頭 | `head_idle` / `head_blink` / `head_spiral` / `head_grin` / `head_annoyed` | ✓（至少 head_idle） |
| 帽子 | `hat` | |
| 眼鏡 | `glasses` | |
| R 手 | `arm_r_upper`、`arm_r_lower`、`hand_r_pinch` / `hand_r_open` / `hand_r_grip` / `hand_r_hatheld` | ✓ |

- 換圖的手：手腕接口位置要一致。`hand_r_hatheld` 是「手抓著帽子」，**照靜止時手的角度畫**：舉起時工具會把手腕轉回正立，帽子不會側躺。
- 鞋子（`foot_*`）不跟著小腿轉，永遠平貼地面。
- 尾巴與燕尾用物理跟隨（烘成關鍵影格）。

## 動作

| 動畫 | 預設 | 內容 |
|---|---|---|
| `idle` | stand-idle | 4 秒循環：呼吸、重心移動、肩髖反向、頭帽延遲、尾巴 S 形、眨眼 |
| `idle_fidget` | stand-fidget | 捏眼鏡轉兩下 |
| `gaze` | hypno-gaze | 預備 → 拉眼鏡、螺旋眼 → 衝向盤面遠手指出（`throw` 事件 0.62 s）→ 停住微顫 → 收回 |
| `react_small` | hat-tip | 點帽、點頭笑 |
| `gaze_dud` | shrug | 聳肩攤手、皺眉 |
| `win_big` | hat-raise | 下蹲 → 抓帽 → 彈起摘帽高舉（`hat_off` 事件）；結尾＝`win_big_loop` 第 0 格 |
| `win_big_loop` | stand-cheer | 帽子在頭上畫圈、遠手打拍 |
| `win_big_end` | hat-on | 戴回帽子（`hat_on` 事件），回到待機 |

所有單次動作都結束在待機用的那張頭、手、帽子，接回 idle 不會殘留表情或手上的帽子。

## 常調的參數（`motion.params.json`）

```json
{ "gaze": { "reach": 0.97, "pointUp": 12, "pinchX": -0.026, "pinchY": 0.03 },
  "react_small": { "gripX": -0.06, "gripY": 0 } }
```

- `pinchX/pinchY`：捏眼鏡時指尖相對手腕的位置（身高比例，y 向上）。手沒對到鏡框就調這個。
- `gripX/gripY`：抓帽緣的點相對帽子底部中心。
- `reach`：指出那隻手伸到手臂長度的幾成，別到 1（打直 IK 會頓）。

## 限制

- 工作室（studio HTML）的「從圖層建立角色」還是拳擊模板；stand34 先用 `character` 指令。
- 一套模板一個姿勢：朝畫面右的角色，交件時左右照畫面對調，或在遊戲裡鏡像。
