# 範例角色：拳擊手（照規格畫的測試角色）

照 [`docs/生圖交付規格.md`](../../../docs/生圖交付規格.md) 畫的一隻拳擊手，用來驗證「AI 圖層 → 自動建骨架 → 套動作」整條流程。比例和姿勢刻意和模板不同（頭較大、站姿較寬、手臂角度不同），就像真的 AI 圖一樣。原本放在 IronJaw 包的 `09_角色試驗/`。

| 檔案 | 內容 |
|---|---|
| `layers/` | 16 張圖層（交付給工作室的檔案，含 `hair_back`、`hair_front`） |
| `composite.png`、`true_joints.json` | 疊起來的角色，以及畫的時候真正的關節位置（用來檢查自動猜關節） |
| `draw_character.py` | 畫這隻角色的程式（`python draw_character.py <輸出資料夾>`） |
| `output/boxer.json` | 用目前 main 的工具、完全不手動調關節跑出來的 Spine 4.3 骨架與 6 個動畫，圖片路徑指向 `../layers/`，可直接 Import Data |
| `output/report.md` | 自動猜關節的誤差、每個動作的流暢度與接縫檢查（目前 6 個動作都 100、接縫全過） |
| `output/總覽.png` | 第 1–6 項修正時的逐幀總覽（舊畫面，僅供對照） |

GIF（`boxer.gif` 約 4 MB）沒有放進 repo，用下面的指令重跑即可產生。第 7、8 項的前後對照見 [`docs/p2-pose-fix/`](../../../docs/p2-pose-fix/)。

## 重跑

在 repo 根目錄執行（需要 Python + Pillow）：

```bash
python scripts/trial/render_gif.py dump examples/characters/boxer/layers /tmp/boxer_alpha
NAME=boxer node scripts/trial/render_frames.ts /tmp/boxer_alpha /tmp/boxer_out examples/characters/boxer/true_joints.json
python scripts/trial/render_gif.py gif examples/characters/boxer/layers /tmp/boxer_out/frames.json /tmp/boxer.gif
```

## 過程中發現的問題與修正

| # | 問題 | 怎麼發現的 | 修正 |
|---|---|---|---|
| 1 | 模板把脖子疊在軀幹上面，脖子往下多畫的那段會蓋住衣領 | 畫角色時，背心領口被一塊膚色蓋住 | 模板改成脖子在軀幹**後面**；交付規格的圖層表與提示詞同步更新 |
| 2 | 照規格「多畫進去 40 px」的圖，自動猜關節反而偏最多：肩、腿根偏 50–60 px，肘、腕偏 30–36 px | 和畫的真實關節位置比對 | 肘、膝、腕改用相鄰兩部件的重疊中心；肩、腿根改從真正的尖端往內縮「半徑 + 30 px」；有脖子圖層時，頭部基準點改用脖子與頭的重疊中心。主要關節誤差降到 5–19 px |
| 3 | 關節對齊畫面不能放大，肩、髖附近的紅點擠在一起很難拖 | 工作室截圖 | 滾輪以游標為中心放大（最多 6 倍）、拖空白處平移、雙擊還原 |
| 4 | **出拳打不出去**：拳頭只前進 104 px，打到底時手臂只伸到 67 % | 看 GIF 幀，再量化 | 求解器的 bug：拳頭 IK 目標和 hip 都掛在 root 下，深度相同，所以拳頭先算，防打直就用「還沒前移的肩膀」限制距離。改成 IK 目標一律最後算：拳頭前進 189 px、手臂伸到 95 %。新增回歸測試（拿掉修正會失敗） |
| 5 | 頭帶飄帶只在兩個待機動作會甩，出拳、受擊、跳躍、慶祝時是硬的 | 看 GIF 幀 | 頭髮／飄帶物理抽成共用，加到出拳、受擊、跳躍、慶祝（一樣可選烘成關鍵影格或保留 runtime 物理） |
| 6 | 慶祝時手臂穿過臉：拳頭往正上方抬，停在臉前，手肘往前頂 | 看 GIF 幀 | 預設改成知道手臂幾何（新增 IK 鏈資訊給預設使用），拳頭沿手臂方向舉到肩膀斜上方、手臂長的 85 % |
| 7 | **跳躍下蹲腳陷進地面、膝蓋沒彎**：腳 IK 目標掛在 root 下，下蹲時整個人連腳一起沉到地面下約 34 px；髖部的擠壓還把大腿一起縮短，膝蓋反而更直 | 看 `jump_compare.png`，量腳和膝蓋角度 | 跳躍新增 `feet` 角色（雙腳 IK 目標）：身體低於站立高度時腳釘在地面，起跳越過站立高度才離地；有腳 IK 時擠壓伸展改在胸部。IK 防打直改成從設定姿勢的長度開始算，不會在第 0 幀把站直的腿往上拉。新增回歸測試 |
| 8 | **慶祝時上臂橫過下巴、拳套停在臉前**：側面角色的前肩就在下巴正下方，從肩膀往上舉（就算伸直 45°）上臂都會掃過下巴 | 看 `celebrate_compare.png` | 改成擺姿勢：上臂往前下 25°（新參數 `elbow`）、前臂往上 65°，再由兩段長度算出拳頭目標；後手壓低 15°，藏在前手後面。新增回歸測試 |

修正後（第 1–6 項）：45 個測試全過；6 個動作流暢度都是 100、接縫檢查全過。工作室匯出的 JSON 和這裡的 `boxer.json` 逐字相同（骨骼、約束、圖層、6 個動畫的雜湊值一致）。

## 還留著的限制

- **慶祝（★進階）**：2026-10-22 起預設改成雙手舉過頭（`elbow` 40、`angle` 85、`swing` 180），前手會經過臉前，這是接受的取捨。
- **自動猜關節**仍有 15–28 px 的誤差（頭頂、髮根、腳踝最大），建議建立骨架前放大檢查一次。這次的動畫是完全沒手動調整的結果。
- 這隻角色是我照規格畫的，不是 GPT／Gemini 的成品。真的 AI 圖可能更不照規格（例如被擋住的地方沒補畫），那時接縫檢查會指出位置。
