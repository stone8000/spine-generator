# AI 拳擊手：照交付規格生圖、驗收、重出的完整範例

來自 Iron Jaw 動態拆解包（2026-10-22）的 `10_美術實作`。AI 生圖交件第一輪（v1）動畫就能用，但驗收挑出 6 處外觀問題；第二輪（v2）只重出那 6 張圖層，全部修好。這個資料夾放的是 **v2 的圖層**，可以當「合格的交件長什麼樣子」的範本。

| 檔案 | 內容 |
|---|---|
| `layers/` | v2 交件的 16 張圖層（1024×1536，含前後髮） |
| `joints.json` | 關節位置（畫布 px） |
| `v1_驗收回饋.md`、`v1_驗收回饋_標示.png` | 第一輪挑出的問題：關節圓頭疊在別的部件上還畫了描邊（像人偶關節）、後肩多畫的部分超出軀幹外緣、後肩補畫有鋸齒 |
| `v2_實作報告.md` | 第二輪的修正內容與驗收結果 |

```bash
spine-motion character examples/characters/ai-boxer/layers --joints examples/characters/ai-boxer/joints.json
```

結果：6 個動作流暢度都是 100、沒有接縫露底、沒有反折，結論「可以用」。

v1 的問題就是交付規格第 2 條鐵律後來補上的「重疊處不要描邊，多畫的部分收在相鄰部件的輪廓裡」，見 [`docs/生圖交付規格.md`](../../../docs/生圖交付規格.md)。
