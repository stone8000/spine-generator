# 分析腳本

需要 Python 3.10 以上、`opencv-python`、`numpy`。

```bash
pip install opencv-python numpy
```

**注意**：區域座標（角色、轉輪、倍數牌…）是依這支錄影的瀏覽器版面寫死的（遊戲畫布在 x 205–1405、y 205–880）。換一支錄影要先用 `info.py` 與 `extract.py` 的整幀截圖確認畫布位置，再改各腳本開頭的座標。

## 執行順序

| 步驟 | 腳本 | 參數 | 產出 |
|---|---|---|---|
| 1 | `info.py` | 影片 | 幀率、總幀數、解析度 |
| 2 | `extract.py` | 影片 輸出資料夾 | 每秒縮圖總表、幾張整幀截圖、全畫面動態能量 |
| 3 | `sheets.py` | 影片 輸出 起秒 迄秒 間隔 欄 列 名稱 [縮圖寬] | 只裁遊戲畫面的縮圖總表 |
| 4 | `analyze.py` | 影片 輸出 | 各區域逐幀差異、轉輪清晰度、角色光流追蹤點、待機熱圖（**主要分析，一次讀完整支影片**） |
| 5 | `bones.py` | 輸出 時間窗編號 | 把追蹤點分成頭、髮、胸、拳等部位，擬合每幀的平移／旋轉／縮放，算週期 |
| 6 | `phase.py` | 輸出 時間窗 起秒 迄秒 | 精確週期（FFT）、正弦振幅、諧波比例、各部位相位差 |
| 7 | `secondary.py` | 輸出 時間窗 起秒 迄秒 | 頭髮扣掉頭部剛體後的殘差、軀幹網格拉伸 |
| 8 | `idle_table.py` | 輸出 csv json | 待機關鍵影格表（畫面總位移） |
| 9 | `rel_table.py` | 輸出 csv | 待機關鍵影格表（Spine 局部值，扣掉父骨骼） |
| 10 | `reels.py` | series.json 起秒 迄秒 | 每輪起轉／停輪時間、停輪間隔 |
| 11 | `reelshift.py` | 影片 輪號 起秒 迄秒 參考秒 | 單一轉輪逐幀位移（反拉、過衝） |
| 12 | `events.py` | series.json 起秒 迄秒 | 每 0.1 秒各區域活動量表，用來切 Bonus／Big Win 段落 |
| 13 | `framediff.py` | series.json 起秒 迄秒 區域列表 | 逐幀列出指定區域的差異（例如找重複幀） |
| — | `heat.py` | 影片 輸出 起秒 迄秒 | 重新計算乾淨時間窗的動態熱圖 |
| — | `plotcurves.py` | 輸出 時間窗 起秒 迄秒 區域:部位:欄 … | 畫部位曲線圖 |
| — | `cropsheet.py` | 影片 輸出 起秒 迄秒 每N幀 欄 名稱 x0 y0 x1 y1 寬 | 任意區域的逐幀總表 |
| — | `export.py` | 影片 分析資料夾 輸出 | 產出報告用的圖片條與 data.json |
| — | `spine_inventory.py` | repo 根目錄 輸出csv | 盤點 repo 裡所有 Spine 骨架檔與匯出版本 |

## Windows 路徑過長

Python 在 Windows 預設不支援超過 260 字元的路徑。路徑很長時，在資料夾前加 `\\?\`，例如 `python analyze.py "影片.mp4" "\\?\C:\很長的路徑\an"`。
