# 分析數據

座標一律是錄影畫面（1920×1032）的像素，y 向下為正。時間是錄影時間碼（秒）。遊戲畫布在錄影中位於 x 205–1405、y 205–880（高 675 px）。

| 檔案 | 內容 |
|---|---|
| `關鍵量測.json` | 所有重點數字的總表：待機、反應、轉輪、Bonus、Big Win、開場。寫程式或做比較時從這裡取 |
| `待機參數.json` | 待機正弦擬合後的關鍵影格表（畫面總位移版），同 `../03_製作規格/待機關鍵影格參數.csv` |
| `逐幀區域動態_series.json` | 每一幀、每個區域與前一幀的平均灰階差（`series`），以及 5 條轉輪的垂直邊緣強度（`sharp`，越低代表越模糊）。區域定義在 `regions` |
| `全畫面動態能量_energy.json` | 整個錄影畫面縮小後的逐幀差異，用來找段落 |
| `部位曲線_csv/` | 13.0–37.5 s 自動旋轉期間，各身體部位每一幀的位移 dx / dy（px）、旋轉（°）、縮放與仍在追蹤的特徵點數。由光流特徵點擬合相似變換得到 |
| `光流追蹤原始資料/` | 每個時間窗、每個角色的 LK 光流追蹤點：`ref` 起始位置、`disp` 每幀位移、`times` 時間、`alive` 是否全程追蹤成功（NumPy `.npz`） |
| `圖表/` | 待機曲線圖、動態熱圖 |

## `series.json` 的區域

| 鍵 | 區域 |
|---|---|
| `L` / `R` | 左／右角色 |
| `c0`–`c4` | 第 1–5 輪 |
| `mult` | 倍數牌 |
| `logo` | 標誌 |
| `bar` | 底部操作列 |
| `bg_top` | 左上背景（對照組） |

## 時間窗

| 編號 | 時間 s | 內容 |
|---|---|---|
| w0 | 7.3–11.0 | 進場後待機 |
| w1 | 13.0–37.5 | 自動旋轉（待機分析主要用這段的 18.2–35.8 s） |
| w2 | 43.5–49.0 | 功能選單期間 |
| w3 | 54.2–64.8 | Bonus 輪盤 |
| w4 | 64.8–66.9 | Wild 擴展與出拳 |
| w5 | 69.9–74.3 | 結算 |

## 使用注意

- 部位曲線在 17.1–18.1 s 有右角色出拳，那段不是待機；右角色多數追蹤點也在出拳時遺失，所以待機擬合只用 18.2 s 之後。
- 左角色的 `abs`（腹部）區域和下拳重疊，數值受手臂干擾，不要直接使用。
- 右角色的 `fist_front`、`belly` 受出拳與遮擋影響，週期性低，不適合當待機參考。
- 讀取 `.npz`：`np.load(path)["disp"]` 的形狀是（幀數, 點數, 2），遺失的點為 NaN。
