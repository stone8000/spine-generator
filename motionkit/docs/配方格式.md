# 配方格式

配方是一個 JSON 檔：告訴工具骨架裡哪根骨扮演什麼角色，以及要做哪些動畫。`spine-motion init` 會產生草稿。

```json
{
  "fps": 30,
  "facing": 1,
  "size": 1,
  "maxSegment": 0.2,
  "ikGuard": true,
  "roles": {
    "hip": "hip",
    "head": "head",
    "hair": ["hair1", "hair2", "hair3"],
    "fistFront": "ik-fist-front"
  },
  "animations": [
    { "name": "idle", "preset": "fighter-idle-bounce", "params": { "intensity": 1.2, "hair": "keys" } },
    { "name": "punch", "preset": "punch", "params": { "reach": 60 }, "facing": 1 }
  ]
}
```

## 頂層欄位

| 欄位 | 預設 | 說明 |
|---|---|---|
| `fps` | `30` | 關鍵影格對齊的幀率 |
| `facing` | `1` | 角色面向：右 `1`、左 `-1`。每個動畫可以個別覆寫 |
| `size` | `1` | 角色大小倍率，1 ≈ 角色高 580 單位（Iron Jaw 量測時的大小）。`init` 和工作室會依骨架高度（不含 IK 目標骨）自動估算 |
| `characterHeight` | — | 改用角色高度（單位）指定大小，等於 `size = characterHeight / 580` |
| `maxSegment` | `0.2` | 一段曲線最長幾秒。Spine runtime 把每段曲線切成 10 條直線播放，段太長大動作會有細微頓挫 |
| `ikGuard` | `true` | IK 目標靠近手臂長度極限時柔性收回，避免手肘打直或翻轉。若骨架已設定 IK softness 可關掉 |
| `ikGuardChains` | — | 個別 IK 目標的保護門檻 `{ "ik-fist": { "knee": 330, "max": 338 } }`（從鏈根骨算起的世界距離）：`knee` 以內不動，之後柔性收到 `max` 為止；`false` 關掉這一條。手臂畫得幾乎打直時，原畫的目標距離就超過 95%，預設保護會在靜止時就把手肘折彎，這時把 `knee` 設成原畫的距離 |
| `roles` | — | 角色 → 骨骼名稱；清單型角色（頭髮鏈等）給陣列 |
| `animations` | — | 要產生的動畫 |

## 動畫

| 欄位 | 說明 |
|---|---|
| `name` | 動畫名稱（已存在會被取代，其他動畫不動） |
| `preset` | 預設名稱，見 [動作預設手冊](動作預設手冊.md) |
| `params` | 預設的參數 |
| `tracks` | 自訂軌道（可以單獨使用，也可以加在預設上） |
| `events` | 額外事件 `[{ "name": "sfx_whoosh", "time": 0.2 }]` |
| `duration` / `loop` | 只有自訂軌道時，指定總長與是否循環 |
| `facing` | 覆寫頂層朝向 |
| `timeScale` | 整體速度：2 = 快一倍（長度減半），事件時間跟著移動 |
| `amplitude` | 整體幅度：每條動作都以靜止值為中心縮放（移動、旋轉以 0、縮放以 1） |
| `boneAmplitude` | 個別骨骼的幅度（乘在 `amplitude` 上）：`{ "ik-fist-front": 0.5 }` 這根骨的畫面與局部軌道都縮成一半，其他骨不變 |
| `intro` / `introName` | 只用在循環：另外寫一支一次性的開頭 `<name>_in`（或 `introName`），從 setup 姿勢淡入。長 `intro` 秒（`true` = 一個循環），每條軌道乘上 smootherstep 包絡，結尾剛好是循環的第 0 格，位置、速度、加速度都接得上。播放：`setAnimation("idle_in")` 再 `addAnimation("idle", loop)`。循環本身不變 |

## 自訂軌道

```json
{ "role": "head", "channel": "rotate", "space": "screen", "type": "wave", "amplitude": 3, "period": 2, "peakAt": 1.2 }
```

| 欄位 | 說明 |
|---|---|
| `bone` 或 `role` | 直接給骨骼名稱，或用角色名稱 |
| `channel` | `rotate`、`x`、`y`、`scaleX`、`scaleY`、`shearX`、`shearY` |
| `space` | `local`（預設）：Spine 骨骼的局部值，等同在編輯器裡 key。`screen`：畫面上的位移／角度，工具依骨架換算（只支援 `x`、`y`、`rotate`） |
| `type` | 動作類型，見下表 |

Spine 慣例：x 往右、y 往上、旋轉逆時針為正；縮放是倍率（1 = 原大小）。

| type | 參數 | 用途 |
|---|---|---|
| `wave` | `amplitude`、`period`（秒）、`peakAt`（最大值出現的秒數）、`offset` | 循環擺動、呼吸、漂浮 |
| `poses` | `points: [{ time, value, ease }]` | 姿勢到姿勢，`ease` 是抵達該點用的緩動 |
| `strike` | `anticipation {value,time,ease}`、`action {value,time,ease}`、`overshoot {amount,frequency,damping}`、`hold`、`recover {time,ease}` | 預備 → 出手 → 過衝 → 停留 → 收回 |
| `spring` | `from`、`to`、`frequency`、`damping`、`delay`、`duration` | 彈簧回位、落地、彈出 |
| `shake` | `amplitude`、`frequency`、`duration`、`envelope`（`decay` / `grow` / `flat`）、`seed` | 受擊抖動、預告顫動 |

緩動名稱：`linear`、`sineIn/Out/InOut`、`quadIn/Out/InOut`、`cubicIn/Out/InOut`、`quartIn/Out/InOut`、`expoIn/Out`、`backIn/Out/InOut`、`snap`（極晚極重，打擊用）。

## 合併規則

- 同一根骨、同一個通道有多條軌道時會相加（縮放是倍率相乘的偏移相加）。
- `screen` 軌道會先依骨架層級由上到下求解：子骨會扣掉從父骨繼承來的動作，只 key 自己需要多動的部分。
- 循環動畫裡每條軌道的長度必須能整除循環長度（例如 2 秒循環可以放 1 秒、0.5 秒的波）。
- 一次性動畫較短的軌道會在結尾停住。

## 骨架需求

- 必須是 **Spine 4.3** 匯出的 JSON。
- 出拳、慶祝這類移動手部的預設，手部角色最好是 **IK 目標骨**。如果手臂是 FK，移動手掌骨不會帶動手臂。
- 要做物理跟隨的頭髮、尾巴，骨骼要是一條父子鏈（`hair1 → hair2 → hair3`）。
